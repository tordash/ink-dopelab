## $965 พันล้าน — ตัวเลขที่เปลี่ยนเกม

สัปดาห์นี้เกิดเหตุการณ์สำคัญในวงการ AI — Anthropic ผู้สร้าง Claude ระดมทุนรอบ Series H มูลค่า $65 พันล้าน ดันมูลค่าบริษัทขึ้นไปที่ $965 พันล้าน แซงหน้า OpenAI ที่อยู่ที่ $730 พันล้าน กลายเป็น AI startup ที่แพงที่สุดในโลกเป็นครั้งแรก

และในวันเดียวกัน Anthropic เปิดตัว Claude Opus 4.8 โมเดลใหม่ล่าสุดที่ถูกออกแบบมาให้ทำงานอิสระได้นานขึ้น ผิดพลาดน้อยลง และตัดสินใจแม่นยำขึ้น

### ใครลงทุน?
- **Lead investors**: Altimeter Capital, Dragoneer, Greenoaks, Sequoia Capital
- **Co-leads**: Capital Group, Coatue, D1 Capital Partners
- **Strategic partners**: Samsung, SK Hynix, Micron (ผู้ผลิตชิป)
- **Hyperscalers**: $15B จาก Amazon + พันธมิตรด้าน infrastructure

### ทำไมถึงแซง OpenAI?
OpenAI ถูก value ที่ $730B ในรอบล่าสุด Anthropic ขยับขึ้นมาเพราะ 3 ปัจจัย:
1. **รายได้โต** — ความต้องการใช้ Claude เพิ่มขึ้นอย่างมาก โดยเฉพาะในองค์กรขนาดใหญ่
2. **Enterprise adoption** — KPMG deploy Claude ให้พนักงาน 276,000 คนทั่วโลก
3. **ความปลอดภัย** — Anthropic เน้น AI Safety ซึ่งองค์กรและรัฐบาลให้ความสำคัญมากขึ้น

### เงินจะไปไหน?
Anthropic ระบุว่าจะใช้เงินก้อนนี้เพื่อ:
- ขยายงานวิจัยด้าน AI Safety และ Interpretability
- เพิ่ม compute สำหรับรองรับ demand ที่โตขึ้น
- ขยาย products และ partnerships

### ฟีเจอร์เด่น

**Effort Control** — ตั้งได้ว่าจะให้ AI ใช้ความพยายามแค่ไหน งานง่ายไม่ต้องคิดเยอะ งานยากสั่งให้คิดลึก

**Dynamic Workflows** — Claude Code สามารถเขียน script ที่สั่งงาน agent อื่นๆ หลายร้อยตัวพร้อมกัน แต่ละตัวทำงานคนละมุม แล้วรวมคำตอบ ตรวจสอบกันเอง จนได้คำตอบที่ converge

**Fast Mode ถูกลง 3 เท่า** — โหมดเร็ว 2.5x ตอนนี้ราคาถูกกว่าเดิม 3 เท่า ทำให้ใช้งานจริงได้คุ้มขึ้น

### มีอะไรน่ากลัว?
Anthropic ยังถือ Claude Mythos โมเดลที่ทรงพลังกว่า Opus ซึ่งไม่เปิดให้ใช้ทั่วไป เพราะมีความสามารถระดับ nation-state ด้าน cyber-offensive — เปิดให้แค่กลุ่มบริษัทและรัฐบาลที่ได้รับอนุญาตเพื่อใช้แพตช์ช่องโหว่

## KPMG 276,000 คน — Enterprise AI ระดับโลก

Big Four firm KPMG ประกาศ global alliance กับ Anthropic ฝัง Claude เข้าไปใน Digital Gateway แพลตฟอร์มหลักที่พนักงานใช้ทำงานจริง

- **Phase 1**: Tax & Legal — ร่าง memo, ค้นหา precedent, สังเคราะห์ข้อมูล
- **Phase 2**: Deal advisory, Risk consulting, Life sciences
- **Phase 3**: Cybersecurity — หาและแก้ช่องโหว่

สิ่งที่น่าสนใจ: การสร้าง AI agent สำหรับช่วยลูกค้าปรับตัวตามกฎหมายภาษีที่เปลี่ยน จากเดิมใช้เวลาเป็นสัปดาห์ ตอนนี้ใช้เวลาเป็นนาที

## สิ่งที่ผู้ประกอบการไทยควรรู้

1. **AI ไม่ใช่ของเล่นอีกแล้ว** — เมื่อ KPMG ให้พนักงาน 276,000 คนใช้ Claude หมายความว่า AI เป็น standard tool ไม่ใช่ experiment
2. **ราคาจะถูกลง** — เมื่อ Anthropic มีเงินขยาย compute Fast Mode ถูกลง 3 เท่า เทรนด์นี้จะดำเนินต่อ
3. **Safety เป็นจุดขาย** — องค์กรใหญ่เลือก Claude เพราะเรื่อง safety ไม่ใช่แค่ performance ถ้าคุณเลือก AI tool ให้ธุรกิจ safety ควรเป็นเกณฑ์
4. **เริ่มใช้ตอนนี้** — ยิ่งรอยิ่งตามหลัง คู่แข่งของคุณอาจใช้ AI automate งานที่คุณยังทำมืออยู่
