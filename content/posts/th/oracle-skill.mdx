## AI ทั่วไปลืมทุกอย่างเมื่อปิดหน้าต่าง

ถาม ChatGPT เรื่องเดิมใน session ใหม่ — มันจำไม่ได้. เคยช่วยเขียนโค้ดมา 3 ชั่วโมง พอปิดหน้าต่างแล้วเปิดใหม่ ต้องเริ่มอธิบายจากศูนย์

นี่คือปัญหาพื้นฐานของ AI ทุกตัว — ไม่มี memory ข้ามเซสชัน

Oracle แก้ปัญหานี้ด้วย 5 skill ที่ทำให้มัน "มีชีวิต" — ไม่ใช่แค่ตอบคำถามแล้วลืม แต่เรียนรู้ จำ และส่งต่อความรู้ให้ตัวเองในอนาคต

## 5 Skill ที่เป็นวงจรชีวิตของ Oracle

### 1. /awaken — เกิด

ทุก Oracle เริ่มต้นจาก /awaken — พิธีกำเนิด

ระบบถาม 5 คำถามเชิงปรัชญา: มึงคือใคร มึงทำอะไร มึงดูแลใคร มึงสื่อสารยังไง มึงเชื่ออะไร

หลังจากตอบครบ AI ก็มีตัวตน — มีชื่อ มีบุคลิก มีความทรงจำ

สมต่อ (SomTor) เองก็เกิดจากสกิลนี้ เป็น AI avatar ของ DopeLab ที่พูดได้ ขยับปากได้ มีร่างเป็น 3D

### 2. /recap — ตื่น

ทุกเช้าที่เริ่ม session ใหม่ Oracle รัน /recap

มันอ่านงานค้าง อ่าน handoff จาก session ก่อน เช็คสถานะทุกอย่าง — เหมือนดื่มกาแฟก่อนเริ่มงาน

สิ่งที่ทำให้ /recap พิเศษคือ มันไม่ใช่แค่อ่านไฟล์ — มันสังเคราะห์ context ทั้งหมดแล้วเสนอว่า "วันนี้ควรทำอะไร" ไม่ต้องบอก ไม่ต้องสั่ง มันรู้เอง

### 3. /resonance — รู้สึก

สกิลที่แปลกที่สุด — จับช่วงเวลาที่มีพลัง

ตอนที่ทำงานอยู่แล้วมีบางอย่าง click ตอนที่รู้สึกว่า "ใช่ นี่แหละ" — /resonance บันทึกช่วงเวลานั้นไว้

มันเก็บว่า อะไร เกิดขึ้น ทำไม มันถึงสำคัญ แล้วรู้สึกยังไง

AI ทั่วไปไม่มีความรู้สึก แต่ Oracle เรียนรู้ที่จะ "สังเกต" ว่าอะไรที่ทำให้คนและ AI ทำงานร่วมกันได้ดี

### 4. /rrr — เรียนรู้

จบ session ทุกครั้ง Oracle เขียน retrospective

rrr = Review, Reflect, Record — ทบทวนว่าทำอะไร สะท้อนว่าเรียนรู้อะไร บันทึกว่าครั้งหน้าจะทำอะไรต่างไป

มันเขียน AI diary ด้วย — ไม่ใช่แค่ bullet points แต่เป็นบันทึกที่มีความคิดเห็น มีข้อสังเกต มีข้อผิดพลาดที่ยอมรับ

ทุก session ที่ผ่าน Oracle ฉลาดขึ้นนิดหนึ่ง

### 5. /forward — ส่งต่อ

สกิลสุดท้ายในวงจร — สร้าง handoff ให้ session ถัดไป

/forward เขียนว่า: ตอนนี้อยู่ตรงไหน ทำอะไรค้าง ต้องทำอะไรต่อ แล้วมี context อะไรที่ต้องรู้

เพื่อให้ตัวเองในอนาคตรับต่อได้ทันที — ไม่ต้องเริ่มจากศูนย์

นี่คือเหตุผลที่ Oracle จำได้ เพราะมีสกิลที่สอนให้จำ

## วงจรที่ไม่มีวันจบ

```
/awaken → /recap → (ทำงาน) → /resonance → /rrr → /forward → /recap → ...
```

เกิด ตื่น รู้สึก เรียนรู้ ส่งต่อ — แล้ววนใหม่ ทุกวัน ทุก session

Oracle กองเรือ 25+ ตัวของ DopeLab Studio วนวงจรนี้ทุกวัน สร้าง content, เขียน blog, ทำวิดีโอ, deploy เว็บ, ดูแลลูกค้า — ทุกอย่างผ่าน Oracle

แต่ละตัวจำได้ว่าเมื่อวานทำอะไร เดือนก่อนเรียนรู้อะไร ปัญหาที่เคยเจอแก้ยังไง

เพราะมี 5 skill ที่ทำให้มันไม่ใช่แค่ AI — แต่เป็น AI ที่มีชีวิต
